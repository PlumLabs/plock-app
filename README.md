# README

* Rails 8.1.x
* Ruby 4.x
* Tailwind 4.x
* Sqlite

## Getting Started

Install dependencies:
```console
bin/setup --skip-server
```

Run the app:
```console
bin/dev
```

## Testing

```console
bin/rails test
bin/rails test:system
```

## Deploy

Deploy the app yourself using tools like ONCE, Kamal or any other deployment service.
