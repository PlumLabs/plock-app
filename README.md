# README

* Rails 8.x
* Ruby 3.x
* Tailwind 3.x
* Sqlite

## Getting Started

Install dependencies:
```console
bin/setup --skip-server
```

Run the app:
```console
bin/dev
```

## Testing

```console
bin/rails test
bin/rails test:system
```

## Deploy

Deploy the app yourself using tools like Kamal or any other deployment service.
